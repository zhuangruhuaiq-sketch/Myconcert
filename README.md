# Myconcert

原创个人观演管理 App，使用 Expo SDK 57、React Native、TypeScript 和 Expo Router。当前版本提供本地记录和原生能力接入，尚非原始产品需求的全部功能。

## 启动

```sh
npm ci
npm start
# 浏览器
npm run web
# 验证
npm run typecheck
npm run lint
npm test
npx expo-doctor
npx expo export --platform all
```

Node.js >= 22.13。Web 采用单页应用输出，部署时应将深链接回退到 index.html；IndexedDB 只在浏览器客户端打开。原生本地优先，离线查看、新建和编辑不依赖账号。Web 当前没有离线缓存 service worker：已加载页面可离线操作，但离线冷启动不保证可用。

## 已连接的功能

- 月历（周一开始、切月）、周视图、月度列表、时间轴、当天全部演出、跨天标记、下一场与开票倒计时。
- 新建/编辑/删除演出，全部状态、票务字段、备注、同行人、标签、评分、观后感、颜色。日期和整数分金额校验；取消场次不参与冲突。
- 详情统一通过 ID 读取最新数据；自定义费用和准备事项可增删改、勾选。所有保存等待持久化成功，写入失败保留原页面并显示原因。
- 名称/艺人/场馆/备注关键词及时间、年份、城市、艺人、场馆、类型、状态、标签、评分筛选；年度统计、按币种支出、费用分类、已观看城市/场馆/时长/平均评分。
- JSON 完整备份、CSV 演出备份、ICS 日程文件导入与导出；先预览错误，再明确跳过或替换重复 ID。JSON 可恢复主题设置；JSON/CSV 将附件内容打包，可能生成较大的文件。
- 图片/视频选择、私有应用目录持久保存、图片预览和视频播放；Web 保存 data URI 至 IndexedDB，单附件限制 20 MB。
- 可编辑绝对时间提醒，7 天/1 天/3 小时预设；保存设置与系统启用分开，拒绝权限时保留设置。Web 明确不支持后台提醒。修改演出时间、取消演出或修改提醒后，需在详情重新启用。
- 单场演出通过系统日历确认窗口添加；全量通过 ICS 导出，由系统决定导入到哪个日历。不会宣称自动双向同步。
- system / light / dark 主题，原创图标已配置到 iOS、Android、启动屏和 Web favicon。

## 数据与恢复

原生使用 SQLite，Web 使用 IndexedDB，分别由平台文件实现同一异步存储接口。数据存于版本化 JSON 快照，金额为整数最小货币单位；不同币种不直接相加。不支持同一数据库的多窗口同时编辑。

旧版 `myconcert.events.v1` 首次迁移前复制到 `myconcert.pre-migration.v1`，保留演出 ID；当前数据存于 `myconcert.backup.v2`。只有数据库不存在时才载入原创演示记录；空数组不会重新填充演示数据。解析/校验失败停止写入，恢复页提供原文和重试入口，禁止用演示数据覆盖。

删除页面记录不删除历史迁移备份及孤立的原生附件文件。彻底擦除请通过系统“清除应用数据”或浏览器清除此站点存储（先备份）。卸载 App、清理浏览器站点数据都会影响本地记录。

ICS 仅导出名称、艺人、时间、城市和场馆，不导出私密订单备注、取票码、详细地址或媒体。JSON/CSV 是私有备份，包含私密字段，请勿公开分享。导入 ICS 支持 UTC、浮动本地时间和全天日期；不支持 RRULE、RECURRENCE-ID、TZID 与 DURATION，预览中会逐条报错，不静默丢弃。

## 原生权限与构建

`app.json` 已配置相册、通知和日历插件。只在用户选择附件、启用提醒或打开日历时触发相关权限/系统操作。没有申请定位、相机或录音权限。

`npx expo export --platform all` 只是 Web/Android/iOS JS 与资源打包，**不是安装包构建或真机权限测试**。可登录自己的 Expo 账号后运行：

```sh
npx eas-cli@latest build --platform android --profile development
npx eas-cli@latest build --platform ios --profile development
```

development 配置为内部测试安装包；iOS 内部分发需要 Apple 账号及设备登记。未在本轮触发云构建、账号创建或付费操作。应用包标识仍是明确占位符 `com.placeholder.myconcert`，发布前改为你拥有的反向域名标识。

深链接：`myconcert://event/<演出ID>`。详情路由不存在时显示可理解提示；通知点击携带演出 ID 打开详情。分享图与原生小组件尚未实现，不能将深链接等同于小组件。

## 尚未接入的服务和原始需求差距

`.env.example` 仅保留未来服务配置名称，当前代码不读取它们；填写密钥不会启用云同步、OCR、公开链接解析或地图。不要填写 service-role key 或任何服务端密钥到 EXPO_PUBLIC 变量。

- 账号登录、云同步和对象存储：未实现。现有 Supabase SQL 只是一份未部署的初稿，UUID 主键也未对齐旧客户端字符串 ID；接入前需设计 ID 映射、冲突处理和私有存储规则，不能直接宣称可用。
- OCR/公开链接解析：未实现，界面明确提示手动填写；公开链接可以保存并由用户打开。
- 地图 SDK：未实现，城市分组列表可用且每条记录可打开。
- 原生小组件、分享图片、海报自动取色、海报墙/纪念票根视图、批量快速录入、事项冲突、可配置字段顺序/常用项/日历密度：未实现。

无需密钥即可使用本轮已实现的本地功能。详细问题、修复证据和真机待验收项见 [docs/QA.md](docs/QA.md)。
