# Myconcert 修复清单与验收记录

检测日期：2026-09-27。修复基线：44bad02。以下“已实现”不等同于“真机已验证”。

## 问题、处理和证据

| 问题 / 复现 | 修复结果 | 验证 |
|---|---|---|
| Web 打包无法解析 SQLite WASM | 平台独立 IndexedDB，原生保留 SQLite | 三平台资源打包通过 |
| Web 删除/无效表单没有反馈 | 跨平台 Modal 确认，按钮捕获错误并在页面显示 | 浏览器验证空表单报错、删除弹窗、取消 |
| 统计/地图列表点不开 | 所有演出行统一使用 Router 详情路由 | 浏览器分别进入详情 |
| 详情连续修改费用/清单/状态覆盖旧值 | 按 ID 从共享状态派生，更新函数使用最新快照 | 浏览器连续修改、刷新持久化；队列测试 |
| 写入失败仍表现保存成功 | 串行写入，成功后发布数据；按钮重复点击锁 | 故障注入测试：失败不发布、下次写入可恢复 |
| 加载完成前能写入 | 共享状态未就绪时只显示加载/恢复页 | 仓库未加载拒绝写入测试 |
| 坏数据被演示数据替代 | 严格校验，保留原文并停写 | 损坏 JSON 测试 |
| 旧数据没有迁移保护 | 迁移前保存原文备份、ID 不变 | 迁移测试 |
| 缺字段 JSON 导入崩溃 | 校验/补齐可选数组，逐条报告错误，预览确认 | 无效预览 UI；部分有效数据测试 |
| 月历无星期对齐/不能切月/同日只开第一条 | 周一表头、切月、日期列表、空日期添加 | 代码检查及浏览器日历 |
| 周视图是假列表 | 独立七天区间，跨天记录匹配每天，附本周列表 | onDay 跨年、跨天测试 |
| 原有演出不能编辑 | 共用新建/编辑表单 | 浏览器编辑城市、状态，其他数据保留 |
| 费用/清单固定为例子 | 自定义增删改、勾选 | 浏览器新增费用、事项、勾选 |
| 非法开票时间抛异常/负数金额进入记录 | 日期/时区/范围校验，精确转整数分 | 无效时间、金额、NaN 评分测试 |
| 搜索污染首页 | 独立路由本地筛选状态 | 代码检查、浏览器导航 |
| 年度统计没有年份过滤、币种混加 | 范围过滤、币种分别汇总、已观看足迹 | 分币种测试、浏览器统计 |
| 倒计时不更新 | 30 秒刷新、AppState 返回前台刷新 | 代码检查；后台恢复真机待测 |
| 导出只是文本框、ICS 不转义 | 文件下载/分享，JSON/CSV/ICS 预览及导入；ICS 转义折行 | 文件落盘往返测试；浏览器下载已发起，内置浏览器未返回下载路径，文件选择器闭环待人工补验 |
| 媒体/提醒仅文字占位 | 系统选择、持久保存、预览播放；提醒编辑/授权/登记/撤回 | 类型/三平台打包；权限与实际投递待真机 |
| 主题和图标文案失实 | 持久化浅/深/系统主题，原创图标用于配置 | 浏览器切主题；Expo Doctor |
| 无真实服务却说填写密钥即可启用 | 设置、README、环境示例明确未实现范围 | 文案与配置审查 |

## 浏览器交互记录

在独立 localhost 测试数据上：空表单保存产生错误；新建“Myconcert 回归演出”；添加交通费 12.34；添加并勾选清单；刷新后金额和完成状态保留；编辑状态为已观看后统计与城市列表可见；两个列表均打开同一详情；删除弹窗可取消；浅色主题切换；无效 JSON 预览显示错误并禁止导入；有效 JSON 确认后在搜索页出现；搜索无结果不影响首页；切换到十月并选择同日三场时，三条均完整显示。

工具的鼠标坐标存在缩放偏差，上述按钮主要用可访问名称定位并以 Enter 激活；不将此等同于全设备触摸验证。人工验收应特别覆盖小屏触摸目标和键盘遮挡。

## 真机及发布前必须补验

1. Android/iOS 安装包启动、离线重启，旧版真实数据库迁移。
2. 相册授权/拒绝/取消，图片和视频选择、重启预览、完整备份跨设备恢复。
3. 通知允许/拒绝、前台/后台/锁屏投递、编辑后重新登记、取消后不再触发、通知点击路由。
4. 系统日历打开、取消、保存、正确结束时间；Android 系统界面不保证返回新增事件 ID。
5. 文件选择器 JSON/CSV/ICS、系统分享取消、文件保存后导回；大文件或空间不足时保留原记录。
6. 改包名，配置自有 Expo/Apple 账号，签名安装包构建。当前未进行云构建和商店提交。
